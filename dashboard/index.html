    System Architecture

    1
    Client Layer
    Browser, mobile app, or a plain API request submits a URL
    2
    Feature Extraction Layer
    URL converted into 28 numeric features: lexical/structural + brand-impersonation signals
    3
    Model Inference Layer
    Cloud-hosted random forest classifier scores the feature vector
    4
    Response Layer
    Returns a score, a risk level, and a SHAP-based explanation of why
